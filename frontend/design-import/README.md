# Flow Design Import Directory

Place your Flow design export here (code, screenshots, SVG assets, or tokens).

## Instructions
1. Drop React components, CSS stylesheets, or raw design screenshots into this directory.
2. When ready, invoke: `"apply design"`.
3. NIKO will faithfully map the design to the headless hooks (`useOverlay`, `useChatStream`, `useApprovals`, `useOrbState`, `useProviderStatus`) and align visual variables in `frontend/src/tokens.ts`.
